# 🖼️ PNG 파일 임포트 설정 자동 적용 가이드

## ✨ PNG 임포트 설정 자동 적용 툴

**Video 폴더의 PNG 파일들**에 **올바른 스프라이트 설정**을 자동으로 적용하는 도구입니다!

### 🎯 **자동 적용되는 설정**

다음 설정이 모든 PNG 파일에 자동으로 적용됩니다:

| 설정 | 값 | 설명 |
|------|-----|------|
| **Texture Type** | `Sprite (2D and UI)` | 🎨 2D 스프라이트로 설정 |
| **Alpha Source** | `Input Texture Alpha` | 🎭 투명배경 지원 |
| **Alpha Is Transparency** | ✅ **체크** | 🌟 완벽한 투명 처리 |

## 🚀 사용법

### **방법 1: Video 폴더 전체 적용** ⭐ **가장 쉬움!**

1. **Unity 메뉴 실행**
   ```
   Unity 메뉴 → Twelve → 🖼️ PNG 임포트 설정 도구 → 📁 Video 폴더 PNG 설정 적용
   ```

2. **확인 다이얼로그**
   - 발견된 PNG 파일 수 확인
   - "적용" 버튼 클릭

3. **완료!** 🎉
   - ✅ 모든 PNG 파일에 설정 자동 적용
   - ✅ 투명배경 완벽 지원
   - ✅ 바로 사용 가능!

---

### **방법 2: 특정 폴더 선택** ⭐ **원하는 폴더만**

1. **폴더 선택 도구 실행**
   ```
   Unity 메뉴 → Twelve → 🖼️ PNG 임포트 설정 도구 → 📂 폴더 선택하여 PNG 설정 적용
   ```

2. **원하는 폴더 선택**

3. **설정 자동 적용**

---

### **방법 3: 선택한 파일들만** ⭐ **정확한 제어**

1. **Project 창에서 PNG 파일들 선택**
   - `Ctrl`을 누르고 여러 PNG 파일 클릭

2. **우클릭 → 🖼️ 선택된 PNG 파일들에 스프라이트 설정 적용**

3. **완료!**

---

## 🔍 **설정 확인하기**

### **Video 폴더 설정 확인**

```
Unity 메뉴 → Twelve → 🖼️ PNG 임포트 설정 도구 → 🔍 Video 폴더 PNG 설정 확인
```

- ✅ **올바른 설정**: 초록색 체크마크
- ❌ **수정 필요**: 빨간색 X 표시와 문제점 표시

## 📋 **적용 전후 비교**

### **적용 전** ❌
- Texture Type: `Default`
- Alpha Source: `None` 
- Alpha Is Transparency: ❌ 체크 해제
- **결과**: 투명배경이 제대로 표시되지 않음

### **적용 후** ✅
- Texture Type: `Sprite (2D and UI)` 🎨
- Alpha Source: `Input Texture Alpha` 🎭
- Alpha Is Transparency: ✅ **체크됨** 🌟
- **결과**: 완벽한 투명배경 지원!

## 💡 **팁과 주의사항**

### **✅ 좋은 점**
- 🎯 **간단함**: 클릭 한 번으로 모든 설정 완료
- ⚡ **빠름**: 대량의 파일도 빠르게 처리
- 🔍 **확인 가능**: 설정 상태 검증 기능 제공
- 🔄 **안전함**: 이미 올바른 설정은 건드리지 않음

### **⚠️ 주의사항**
- PNG 파일만 처리됩니다 (JPG, GIF 등은 제외)
- 기존에 수동으로 설정한 특별한 설정이 있다면 덮어씌워집니다
- 대량 파일 처리 시 시간이 걸릴 수 있습니다

### **🚨 문제 해결**
- **"PNG 파일 없음"**: 선택한 폴더에 .png 파일이 있는지 확인
- **"폴더 없음"**: Assets 폴더 내부의 경로인지 확인
- **설정이 적용되지 않음**: Unity 에디터를 재시작해보세요

## 🎯 **권장 워크플로우**

1. **PNG 파일 준비** → Video 폴더에 배치
2. **설정 자동 적용** → 이 도구 사용
3. **설정 확인** → 검증 도구로 확인
4. **사용** → 게임에서 바로 사용 가능!
